## 4. CFAR hardware block (rtl/cfar_ca_1d.v)

- **Bit-exact with the Python fixed-point model on all 45 tests** (1,868,856 decisions, 2,450,438 cells): directed (zeros, spikes, close spikes, clutter edge, full-scale values, alpha extremes, line-length boundaries), random lines with and without input stalls, and range lines from simulated scenes; (N_TRAIN, N_GUARD) = (8,2), (16,2), (32,4). Simulator: Vivado 2025.2 xsim (batch).
- **Mutation test:** 7/7 non-equivalent RTL mutants caught; 1 equivalent mutant (an always-zero sum bit) correctly produces no difference.

## 6. What this does NOT show

- Real radar data, real drones or birds: all data are simulated point-scatterer models.
- Hardware behaviour: the RTL ran in simulation only; resources and Fmax are tool reports.
- Performance of a complete radar: no tracking, no antenna/beam model, no multipath, no RCS model beyond point scatterers with fixed amplitude ratios.
- The INT8 classifier is simulated by fake quantization, not run as an integer kernel.
